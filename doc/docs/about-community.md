Questions and discussions about coursier take place on

- GitHub issues, in the repository of each project, like [the ones of coursier itself](https://github.com/coursier/coursier/issues),
- [GitHub discussions](https://github.com/coursier/coursier/discussions), in the main coursier repository,
- the [Scala Discord](https://discord.com/invite/scala), in its `#tooling` channel.
