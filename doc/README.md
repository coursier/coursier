This directory contains the sources of the coursier website, published to <https://get-coursier.io>.

It relies on [docusaurus](https://docusaurus.io/) and [mdoc](https://scalameta.org/mdoc). Its pages
live under [`docs`](docs), and the docusaurus configuration under [`website`](website). See
[the website page](docs/dev-website.md) for how to build it.
